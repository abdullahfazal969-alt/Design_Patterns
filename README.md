# Multi-Agent System using Design Patterns

This project is a hands-on demonstration of core software design patterns, implemented in Python to build a simple, modular, and scalable multi-agent system.

The primary goal is to showcase the practical application of the following patterns:
- **Singleton**
- **Factory**
- **Observer**
- **Strategy**

This system is built from the ground up to illustrate architectural principles rather than relying on external agentic frameworks.
